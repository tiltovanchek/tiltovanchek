**Исследователь (анализ данных), дипломный проект** — НИЯУ МИФИ  
*Апрель 2024 — июнь 2025*

- Написал на Python симулятор методом Монте-Карло (несколько млн частиц за прогон), который строит синтетический снимок детектора. Ускорил расчёт с помощью Numba в ~4 раза: с 30 до 7 минут.
- Проверил гипотезу об источнике аномального сигнала: симуляция показала, что основной пучок не даёт сигнал на больших углах. Установил, что аномалию дают частицы из другого источника.
- Проверил модель на реальных данных: оба пика в угловом распределении совпали с наблюдаемыми.
- Аппроксимировал и интерполировал данные (SciPy), строил графики в Matplotlib для руководителя, защиты и статей.
